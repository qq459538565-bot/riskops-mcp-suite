Honest Caveat: Pure Deterministic Math Only — Bring Your Own Price Feed

QuantCalc-JS does not pull live stock quotes, ticker fundamentals, or SEC filings from Yahoo Finance or any external market API. That is deliberate: external scrapers break every few months and force you to manage API keys and rate limits. You pass in the numbers (from user input or your own price feed), and QuantCalc-JS handles the math deterministically with zero server bills. Also note: calculateIrr solves periodic cashflow IRR for equal intervals (t0, t1, t2...), not irregular calendar-dated XIRR.
